# cs5383-project

> Proyecto del curso **CS5383 – Verificación y Pruebas de Software** · UTEC

Proyecto grupal de pruebas de software sobre un sistema real: **[Advantage Online Shopping](https://www.advantageonlineshopping.com/)** (Caso 2 — E-commerce). Es el primero de una secuencia de 3 proyectos que reutilizan el mismo caso, siguiendo el proceso de pruebas de **ISTQB**.

## Contexto

Advantage está a semanas de su campaña de temporada alta y le preocupa que errores en el carrito o en la aplicación de tarjetas de regalo y promociones generen pérdida de ventas o descuentos mal calculados.

**Alcance funcional:** registro y login, catálogo y búsqueda, carrito, tarjetas de regalo y promociones, checkout, lista de deseos e historial de pedidos.

## Proyecto 1 — Planificación, análisis y diseño de pruebas

| Sección | Contenido |
|---|---|
| **5.1 Planificación** | Plan de pruebas (alcance, objetivos, criterios de entrada y salida, esfuerzo, riesgos, cronograma), estrategia y niveles de prueba |
| **5.2 Análisis** | Condiciones de prueba, matriz de trazabilidad requisito → condición y priorización por riesgo |
| **5.3 Diseño** | Al menos 15 casos de prueba sobre 4 o más funcionalidades, con técnicas de caja negra: partición de equivalencia, valores límite, tabla de decisión y transición de estados |
| **5.4 Ejecución** | Ejecución manual de los casos de prioridad alta sobre el sitio real y reporte de hallazgos con evidencia |
